# SOUNDSCAPE PILOT

A real, self-hosted command center for musicians, radio stations, and the music industry.
 No third-party browser engine, no simulations — a proprietary FastAPI backend with real scraping, real SMTP dispatch, rotating owner accounts, and SQLite persistence.

## Features

- **Multi-Vector Radio Autopilot**: Searches College, Military, Satellite, FM, AM, and Internet radio using public APIs and curated directories.
- **SOTA Booking Agent**: Finds real venues in any US state, generates EPK text, drafts contracts, and sends outreach emails.
- **Press Release Wire**: Curated media-outlet database with tiered targeting and real dispatch.
- **Master Autopilot DAG**: Creates persistent tour-routing tasks in the database for follow-up automation.
- **Aegis Security Center**: VPN/Ghost/Anti-tracking controls (software bridge in this build).
- **Platform Hub**: One-click access to DistroKid, LANDR, SoundCloud, CD Baby, ReverbNation, BandLab, Pandora, Spotify, Amazon Music, YouTube Music, Deezer, iHeartRadio, Facebook, X, Instagram, TikTok.
- **Owner Email Rotation**: `ray@titan2026`, `keith@titan2026`, `joni@titan2026`, `paige@titan2026`.

## Quick Start

```powershell
# 1. Enter the project directory
cd "C:\Users\reddi\OneDrive\Desktop\Titan7B\titan7"

# 2. Create and activate virtual environment (first time only)
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt

# 3. (Optional) Configure real SMTP so emails actually send
$env:TITAN_SMTP_HOST = "smtp.gmail.com"
$env:TITAN_SMTP_PORT = "587"
$env:TITAN_SMTP_USER = "your-real-email@gmail.com"
$env:TITAN_SMTP_PASS = "your-app-password"

# 4. Run
.venv\Scripts\python launcher.py
```

The launcher will start the server and open `http://127.0.0.1:8765` in your default browser.

## SMTP Configuration

Without SMTP credentials, dispatches are logged in the database as `failed` with the reason "SMTP credentials not configured". Set the environment variables above to send real emails.

## Packaging for Partners

This project includes build scripts to create distributable Windows installers:

- **`.exe` (portable)**: Build with PyInstaller using `build_exe.bat`
- **NSIS installer**: Build with `build_installer.bat` (requires NSIS installed)
- **`.msi` installer**: Build with `build_msi.bat` (requires WiX Toolset installed)

Run from PowerShell:

```powershell
.\.venv\Scripts\pip install pyinstaller
.\build_exe.bat
```

Outputs will appear in `dist/`.
